Known Limitations — Do Not File as Bugs

Firmware version is always "unknown" — SysEx query not implemented.
Firmware update via .syx file is a UI placeholder — not functional.
Effect type (Distortion/Chorus) resets to first option on page reload (sent via NRPN, not in patch SysEx data).
Delay and Reverb preset selection in Effects tab is display-only — Circuit Tracks has no remote CC/SysEx for preset selection.
CC-based tempo is approximate — only 128 steps for 40–240 BPM range (~1.6 BPM resolution).
Web MIDI (and SysEx) requires Chrome or Edge — Firefox/Safari not supported.
Mute/Solo in Mixer is UI-only — no MIDI CC for these on Circuit Tracks.
Sample transfer to device via MIDI not available — use SD card or Novation Components.
Synth 1/2 tracks in Sequencer don't trigger notes (MIDI path is external) — only Drum and MIDI tracks trigger NoteOn.
Undo/Redo keyboard shortcuts (Ctrl+Z) are captured but not implemented.
